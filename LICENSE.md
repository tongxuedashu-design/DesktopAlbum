## English

Desktop Album combines a settings center, a modified Reminisce skin, and the Rainmeter engine. Each component retains its own license. This file describes their origins and is not a single license for the combined distribution. A release license still needs to be selected by the publisher for the newly added C# settings center, icon, sample image, and modifications.

### Reminisce

The original skin comes from [misterhaan/Reminisce](https://github.com/misterhaan/Reminisce), credited as `Copyright (c) 2018 misterhaan`. The repository LICENSE specifies MIT. The skin Metadata separately specifies `Creative Commons Attribution - Non - Commercial - Share Alike 3.0`.

These notices differ; both originals and the attribution are retained. The applicable license for each skin file needs to be clarified with upstream before public release. Until then, the complete bundle cannot be labeled MIT or represented as approved for commercial use.

### Rainmeter

[Rainmeter](https://github.com/rainmeter/rainmeter) uses GNU GPL v2. The portable release includes unmodified Rainmeter 4.5.28.3936 (64-bit), required plugins, and language files, retaining their official digital signatures. The settings center controls the engine through commands.

The complete corresponding Rainmeter source is included at `Docs/sources/Rainmeter-v4.5.28.3936-source.zip` in the portable release, with its original license and build scripts. This app's separate source archive does not include engine binaries; developers can copy them from a separate official portable Rainmeter installation using `src/Prepare.ps1`.
