# 照片库 / Photo Library

## 中文

将自己的 JPG、JPEG、PNG 或 BMP 照片放入此处，也支持子文件夹。也可以在设置中心选择其他照片文件夹。

`sample-landscape.png` 是绘制的示例图，可以删除。添加自己的照片后，请不要将这个已使用的文件夹重新打包作为公开发行包。

## English

Put your JPG, JPEG, PNG, or BMP photos here. Subfolders are supported. You can also choose another folder in the settings center.

`sample-landscape.png` is a drawn sample image and can be deleted. After adding your own photos, do not repackage this used folder as a public release.
